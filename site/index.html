    What your security team gets

    Agents become something a security team can approve, the same way they approve a new employee's access.

    Control

    Each agent has a short written rulebook: which tools, which data, which destinations, and what needs a person. Rungated enforces it on every call.

    Protection

    Prompt injection, leaked keys, personal data and data theft are hidden or stopped before they leave. A misbehaving agent is isolated in moments.

    Proof

    Every decision lands in a tamper evident log, with who approved what and why. Ready for auditors and your customers' security reviews.

    One checkpoint between your agents and everything they touch

    Model calls, tool calls and web traffic pass through the same decision engine and the same audit trail. Basic checks take under a millisecond.

    1. Write the rulebook

      One short file per agent: allowed tools, data that must never leave, what needs approval.

    2. Point the agent at Rungated

      Usually one line: the model base URL becomes /llm/openai/v1 on your gateway.

    3. Watch, then enforce

      Start in observe mode to see what it would stop, then turn on blocking and approvals in Slack.
