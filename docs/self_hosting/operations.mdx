## Health and version

```bash
curl localhost:8080/v1/health
curl localhost:8080/v1/version
```

## Metrics

Prometheus metrics are served at `/metrics`, including `rungated_decisions_total` and `rungated_decision_latency_seconds`. The endpoint needs an API key with read access, sent as `Authorization: Bearer <key>`. The Helm chart's ServiceMonitor sends the key from the chart secret.

## Audit log

Every decision is written to a hash chained audit log.

```bash
rungated audit verify --gateway http://localhost:8080 --api-key "$RUNGATED_API_KEY"
```

The chain detects edits and deletions inside it. To detect someone replacing the whole log, copy the head hash somewhere you control on a schedule.

## Containment

```bash
curl -X POST localhost:8080/v1/contain -H "Authorization: Bearer $RUNGATED_API_KEY" \
  -d '{"agent_id":"finance-agent","reason":"investigating"}'
curl -X POST localhost:8080/v1/release -H "Authorization: Bearer $RUNGATED_API_KEY" \
  -d '{"agent_id":"finance-agent"}'
```

Containment survives restarts.

## Durability

With the local event bus, audit writes are asynchronous and can be lost if the process is killed within a few tens of milliseconds of a decision. Use NATS JetStream, in Enterprise, when you need every record.

## Upgrades

Roll replicas one at a time. Policy and manifests reload at start.
