---
title: "Run models locally"
description: "Download the free models and run them inside the gateway."
---

The free models run inside the gateway process on CPU. Text never leaves your machine.

<Steps>
  <Step title="Get the ONNX build">
    Local models need ONNX Runtime. The easiest way is the ONNX image:

    ```bash
    docker pull ghcr.io/amareshhebbar/rungated:latest-onnx
    ```

    Or build it yourself with ONNX Runtime installed (`make tools-onnx` on Fedora):

    ```bash
    CGO_ENABLED=1 go build -tags onnx -o bin/rungated ./cmd/rungated
    ```
  </Step>
  <Step title="Download the models">
    ```bash
    rungated models pull rungated-embed-mini
    rungated models pull rungated-guard-mini
    ```

    Files go to `~/.local/share/rungated/models`. Set `RUNGATED_MODELS_DIR` to change it. Every file is checked against its SHA256.
  </Step>
  <Step title="Turn them on">
    ```yaml
    embed:
      enabled: true
      model: rungated-embed-mini
    tier1:
      enabled: true
      model: rungated-guard-mini
      library_path: /usr/local/lib/libonnxruntime.so
    ```

    Start the gateway. The log shows `local models loaded`.
  </Step>
</Steps>

## How the embedder scores text

At startup the gateway embeds a bank of about 60 known attacks and 40 safe look alikes in many languages. Each text the agent reads is split into chunks, embedded, and compared with the bank. A chunk close to an attack and not closer to a safe example scores high.

| Setting | Default | Meaning |
| --- | --- | --- |
| `embed.threshold` | 0.72 | Similarity where the score crosses 0.5 |
| `embed.bank_path` | built in | Your own bank as JSONL: `{"text": "...", "label": 1}` for attacks, `0` for safe |
| `embed.max_len` | 512 | Tokens per chunk |

Add your own attacks and safe examples to the bank to tune it to your domain without training anything.

## Using both

When the embedder and the classifier are both on, the higher score wins. When hosted models are also on, they run first and these local models take over if the hosted ones are unreachable or a trial ends.
